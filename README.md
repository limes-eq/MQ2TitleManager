# MQ2TitleManager
MQ Version of the EQ titles window with searchable prefixes/suffixes

- Download MQ2TitleManager.dll from releases, or download source and compile yourself against the current Macroquest emu branch
- Place in macroquest/plugins/
- In game, run /plugin MQ2TitleManager
- The plugin adds the */titles* command to open the ImGui window
